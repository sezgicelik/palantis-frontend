# Noxara Icon Set

Kaynak: [game-icons.net](https://game-icons.net)
Lisans: **CC BY 3.0**

Sanatcılar: Lorc, Delapouite, Skoll, Willdabeast, DarkZaitzev, Caro Asercion,
(credit listesi: https://game-icons.net/about.html)

Noxara'da kullanilan 131 ikon ortacag/fantezi temasi icin secilmistir.
Kaynak SVG'ler 000000 (siyah) + transparent olarak indirildi — `filter: invert()`
veya CSS tint ile renk ayarlanabilir.

## Kullanim ornegi

```html
<img src="/icons/noxara/piyade.svg" class="nox-icon" alt="Piyade">
```

```css
.nox-icon {
  width: 24px;
  height: 24px;
  filter: invert(100%) drop-shadow(0 0 2px rgba(212, 162, 87, 0.5));
}
```
